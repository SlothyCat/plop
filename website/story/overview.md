# The Story

This site documents how **plop** — a local-first iOS expense tracker — was designed and built,
using a deliberate *brainstorm → write a plan → get approval → implement* loop. The
[Reference](/reference/roadmap) holds the full engineering specs; this section narrates the
decisions behind them.

<br>

:::voice[From the author]
Even though I have been using an existing finance tracker app (`Dime`), I wanted a functionality to 
**export to Google Sheets** so that I can do my monthly budgeting better.

I positioned myself as a target user: a busy city dweller who wants **simple and easy** finance tracking.

I wanted to try Vibe Coding with specs planning, something that I have seen in my workplace.
After this project, I plan to make use of multiple agents and an orchestrator for subsequent developments.

(This might have been done implicitly by `Claude` when it implements the features as 
it will opt for subagent execution instead of inline execution)
:::
